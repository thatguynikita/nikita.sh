# 404.html — the "page not found" page

What shows up if you follow a broken or mistyped link on nikita.sh. It
keeps the same terminal look as the rest of the site (background rain,
CRT scanlines, the same header) instead of dumping visitors on a generic
error page.

## What's on the page

- A fake terminal command trying — and failing — to find whatever page
  was requested, echoing back the actual path you typed or followed
- A tired cat lying in a pile of spilled condensed-milk cans, tinted to
  match whichever color theme is active
- A short, apologetic message
- Links back to the homepage and the résumé

## Language

Like the résumé page, there's an EN/RU toggle, but no other
interactivity — no commands to type here.
