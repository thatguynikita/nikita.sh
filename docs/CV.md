# cv.html — the résumé page

The actual résumé — meant to be read, linked, or printed, unlike the
playful terminal homepage. It's styled to match the rest of the site
(same look, each section headed like a fake terminal command, e.g.
`cat about.txt`), but there's nothing to type here: just a language
toggle and a print button.

## What's on the page

In order, top to bottom:

- Header — name, role, contact links, a few quick facts, and a photo
- About
- Experience — job history, with dates, achievements, and the tech used
  in each role
- Education
- Certifications
- Languages spoken, with proficiency bars
- Skills, as a table
- A personal "notes.txt" section with some lighter personality traits
- A sign-off line

## Printing

The print button (or your browser's own print function) gives a clean,
plain black-on-white version — all the terminal decoration, color
effects, and photo tinting are stripped out for print.

## Language

The EN/RU toggle in the header switches every section on the page at
once, and remembers your choice next time you visit (shared with the
terminal homepage).
